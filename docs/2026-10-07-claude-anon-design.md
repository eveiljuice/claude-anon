# claude anon — «инкогнито-режим» для Claude Code

- Дата: 2026-10-07
- Статус: спека, ожидает ревью
- Платформа: Windows 11, Claude Code (терминал; где возможно — desktop surface)

## 1. Цель

Claude anon — режим Claude Code «как приватное окно браузера»: Claude стартует или
работает без знания о пользователе, не оставляет следов на диске, глушит телеметрию
и **виден глазом** — клиент визуально перекрашивается в фиолетовый, пока
режим активен. Официальное название режима: **claude anon**.

Список отключенного (утверждён пользователем):

1. **Чистый контекст** —Claude не видит auto-memory/MEMORY.md, CLAUDE.md, историю подсказок.
2. **Не сохранять сессию** — transcript не остаётся на диске.
3. **Не писать память** — записи в память блокируются.
4. **Без телеметрии** — DISABLE_TELEMETRY и связанные, error-reporting тоже.

Визуальная часть (утверждена пользователем):

- фиолетовая полоса (band) вплотную над полем ввода, с собственным фиолетовым маскотом;
- фиолетовый лейбл **claude anon** в футере у индикатора режимов (рядом с `focus`,
  `memory paused`);
- заголовок вкладки/окна терминала — **Claude Code Anon**, пока режим активен.

## 2. Формы активации (обе, утверждено)

### 2.1 Лаунчер `anon` — полное инкогнито при старте

PowerShell-скрипт `anon.ps1` (+ `anon.cmd`-шим для запуска из Win+R/cmd), живёт в
`%USERPROFILE%\Desktop\timo\claude-anon\`.

1. Профиль: `CLAUDE_CONFIG_DIR=%USERPROFILE%\.claude-anon`. При первом запуске
   создаётся каталог; копируются **только** `%USERPROFILE%\.claude.json` и
   `%USERPROFILE%\.claude\.credentials.json` (если отсутствуют в профиле, но есть в
   основном) — этого достаточно для входа в аккаунт без переноса истории/памяти
   (подтверждено: оба пути идут за CLAUDE_CONFIG_DIR).
2. В профиле пишется `settings.json`:
   `{"cleanupPeriodDays": 0, "autoMemoryEnabled": false}` — официальное «транскрипты
   не пишутся вовсе» и отключение memory-фичи.
3. Env на процесс: `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`,
   `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`, `DISABLE_TELEMETRY=1`,
   `DISABLE_ERROR_REPORTING=1`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`,
   маркер `CLAUDE_ANON=1`. Все ставятся как `1` (любое непустое значение считается
   установленным). Опционально `CLAUDE_BRAND=Claude Anon` — работает на форке
   ОКонфига (env читает бренд-текст), на стоке игнорируется безвредно.
4. Ставит заголовок консольного окна/вкладки `Claude Code Anon` до старта клиента,
   после выхода восстанавливает прежний.
5. Запускает `claude --plugin-dir <канонический каталог мода>`.

### 2.2 Команда `/anon` — режим внутри обычной сессии

Через мод (см. 3). Контекст, уже загруженный к моменту включения, остаётся в сессии —
это неизлечимо и честно указывается в полосе (см. текст band).

## 3. Компонент: мод `claude-anon`

Hooks-модуль (не shell-hooks, а function-hooks движка). Канонический источник:
`%USERPROFILE%\Desktop\timo\claude-anon\mod\claude-anon\` (git-репозиторий —
задел на публикацию как плагин/marketplace). Для разработки во время этой сессии
рабочая копия: `C:\Users\ok\.claude\dev-mods\18c366b7-e89c-4104-ab72-ba867c0c4c1f\claude-anon\`.

Файлы: `.claude-plugin/plugin.json`, `hooks/hooks.json` (`{ "modules": ["./register.tsx"] }`),
`hooks/register.tsx`, `types/index.d.ts` (контракт `$.state`), тесты `*.test.ts`.

### 3.1 Состояние

- `$.state` (сессия): `{ anonOn: boolean, launcherMode: boolean, restoredTitle: string | null }`.
- `$.store` (межсессионное): `anonManifest: Record<sessionId, { transcriptPath: string; subagentsDir: string }>` —
  список сессий, у которых transcript подлежит удалению; источник сирот после крэша.

### 3.2 Поведение

- `session.start`: регистрация команды `/anon` (`$.command.register`); дочистка сирот
  из `anonManifest` (удаляем файлы, чей sessionId ≠ текущей сессии, запись снимаем);
  читаем env `CLAUDE_ANON=1` → `launcherMode` = вкл. `anonOn` сразу; в `launcherMode`
  `/anon off` отказывается с тостом «в этом профиле инкогнито всегда».
- `command.run` (`/anon [on|off]`): переключение `anonOn`; при каждом превращении в «вкл»
  — запись текущей сессии в `anonManifest`. Тосты: `claude anon on — сессия не
  сохранится` / состояние при off.
- `ui.render {component: 'AbovePrompt'}`: при `anonOn` рисуем фиолетовую полосу
  (Box `backgroundColor` truecolor) во всю ширину `e.bodyColumns` с ASCII-маскотом
  (свой, фиолетовый; аналог ✻-клёйда) и текстом:
  `✻ CLAUDE ANON · сессия не сохранится · память не пишется` (в mid-session-режиме
  второй сегмент меняется на `контекст уже загружен`). При
  выключенном — ничего. Уступаем место опросам: если `e.hasSurvey`, пропускаем.
- `ui.render {component: 'SessionMode'}`: при `anonOn` добавляем/рисуем лейбл
  `claude anon` фиолетовым в ряду режимов футера.
- `tool.call` (Write, Edit): при `anonOn` и пути внутри каталога памяти
  (`<CFG>/projects/<sanitized-git-root>/memory/`) → `{ deny: 'claude anon: запись в память отключена' }`.
  Остальные вызовы — `next(e)`.
- `prompt.compose`: при `anonOn` добавляем последнюю секцию (`scope: 'session'`):
  правила режима (не писать память, не персонализировать, не ссылаться на память).
- `session.end`: при наличии текущей сессии в `anonManifest` удаляем transcript
  (путь берём из input события, если он там есть; фолбэк —
  `<CFG>/projects/<munged-cwd>/<sessionId>.jsonl` + каталог `subagents/`) и снимаем
  запись; событие срабатывает и по signal. Заголовок окна возвращаем (терминал).
- Терминальный заголовок: прямого API нет. При включении/выключении мод спавнит через
  `$.process` без консольного мусора `powershell -NoProfile -Command
  "$Host.UI.RawUI.WindowTitle='Claude Code Anon'"` (SetConsoleTitle меняет заголовок
  общей консоли/вкладки WT); при восстановлении — сперва читаем прежний тем же приёмом.
  Только `e.surface === 'terminal'`.
- Палитра (константы мода, подгоняются при реализации): ANON_BG `#4b2e83`,
  ANON_FG `#f2ecff`, ANON_ACCENT `#b98cff`, ANON_MASKOT `#9b6bff`.

### 3.3 Семантика off (утверждаемая по умолчанию)

Сессия, в которой `/anon` хоть раз включали, **не сохраняется даже после `/anon off`** —
уже попавшее в transcript не «раз-инкогнитить». `/anon off` выключает только полосу,
лейбл и блокировки на будущее. Это правило озвучивается тостом при off.

## 4. Вне объёма

- Перекраска нативной рамки поля ввода и нативного маскота (Clawd) — ядерные элементы,
  мод-API на них нет; полоса примыкает сверху, маскот рисуем свой.
- Полноценное отдельное приложение (TUI на Agent SDK) — отклонено пользователем.
- Кросс-платформенный лаунчер (Windows первый; Linux-скрипт возможно позже).
- Замена текста нативного индикатора permission mode (`bypass permissions on` и т.п.) —
  ядерный; наш лейбл идёт рядом с ним.

## 5. Известные ограничения и дыры

1. **Bash-обход записи памяти** в mid-session `/anon`: deny-hook закрывает Write/Edit;
   Bash-запись (echo >>) остаётся теоретически возможной — в launcher-режиме память
   отключена полностью на уровне env, в mid-session закрывается инструкцией
   `prompt.compose`. Полностью на мод-уровне это не лечится — документируем.
2. **Хард-килл**: `session.end` не гарантирован → сироты дочищиваются при следующем
   `session.start` по `anonManifest` (за этот риск отвечает сам мод).
3. **Заголовок вкладки**: если клиент сам перезаписывает заголовок во время работы,
   наш заголовок мог бы перебиваться; мод не переспамливает по таймеру (YAGNI) —
   восстанавливаем на toggle и session.start, при наблюдаемой борьбе пересмотрим.
4. **Два профиля плагинов**: лаунчерный профиль имеет собственный каталог плагинов —
   мод подключается туда через `--plugin-dir` на канонический источник, обновление
   одного источника всегда живо в обоих местах.
5. `CLAUDE_BRAND` — форк-специфика (ОКонфиг), на стоке тихо игнорируется.

## 6. Тестирование

- `claude plugin validate <mod folder>`, `tsc -p` (после первой загрузки движок
  выписывает типы), `claude plugin test <mod folder>`.
- Автотесты мода: toggle-логика `/anon` и состояние; deny-правило Write/Edit по
  путям памяти; манифест-очистка сирот (удаление чужих сессий, нетронутая текущая);
  band рисуется при on и пуст при off; hasSurvey уступает.
- Смоук вручную: `/anon on` → полоса+лейбл+тост, Write в MEMORY.md отказан; `/exit` →
  jsonl-файл сессии отсутствует; запуск `anon.cmd` → чистый профиль создан, полоса с
  старта, `history.jsonl` профиля пуст, телеметрия-переменные в окружении процесса.
