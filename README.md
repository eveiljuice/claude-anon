# claude anon — инкогнито-режим для Claude Code

Режим «как приватное окно браузера»: Claude работает без знания о пользователе,
не оставляет следов на диске и глушит телеметрию, а клиент визуально
перекрашивается в фиолетовый, пока режим активен.

## Что отключено

1. **Чистый контекст** — Claude не видит auto-memory/MEMORY.md, CLAUDE.md, историю
   подсказок и не берёт её из пер-ходовых вложений памяти; строка включённой сессии
   снимается из `history.jsonl`, todos-файлы и file-history снапшоты удаляются при
   выходе.
2. **Не сохранять сессию** — транскрипт удаляется при выходе (и при хард-килле —
   дочищивается на следующем старте по манифесту).
3. **Не писать память** — Write/Edit под каталогом сессий движка отказаны.
4. **Без телеметрии** — DISABLE_TELEMETRY, DISABLE_ERROR_REPORTING,
   CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC.

## Два способа включить

- **Полное инкогнито** — запустить `anon.cmd` (или `anon.ps1`): отдельный профиль
  `%USERPROFILE%\.claude-anon`, копия только `.claude.json` и credentials,
  транскрипты отключены на уровне настроек (`cleanupPeriodDays: 0`), память
  отключена env-ами. `/anon off` в этом режиме отказывает — профиль всегда
  анонимен.
- **Внутри обычной сессии** — команда `/anon [on|off]` или **Shift+Tab**. Контекст,
  уже загруженный к моменту включения, остаётся (об этом честно говорит полоса —
  `context loaded before going anon`); всё, что движок собрал бы после включения,
  не уходит: секции памяти системного промпта срезаются, пер-ходовые вложения памяти
  (реколл, ре-инъекция CLAUDE.md/MEMORY.md, team-контекст) глушатся, в новой беседе
  (после `/clear`) персональные блоки первого хода вырезаются — полоса покажет
  `memory unloaded`. Сессия, где `/anon` хоть раз включали, не сохраняется даже
  после off (sticky).

Первое включение идёт через диалог согласия (аналог WARNING
`dangerously-skip-permissions`): что произойдёт, что не возвращается назад и
`No (default)` / `Yes, I accept`. Согласие запоминается между сессиями, диалог
больше не повторяется; Esc — отклонение, ничего не включается. В лаунчере
диалога нет — согласие выражено самим запуском.

## Внешне

- фиолетовая полоса над полем ввода с маскотом;
- фиолетовый лейбл `· claude anon` в футере рядом с нативными режимами;
- заголовок окна/вкладки терминала `Claude Code Anon`, пока режим активен.

## Установка

Плагин грузится из этого каталога (локальный marketplace-путь), поэтому
обновления мода подхватываются без переустановки:

```bash
claude plugin marketplace add <путь к этому каталогу>
claude plugin install anon-mode@claude-anon
```

Для GitHub-репликации: `claude plugin install anon-mode@claude-anon --marketplace eveiljuice/claude-anon`
(когда репозиторий опубликован).

### Shift+Tab (опционально)

Плагины регистрируют команду `/anon`, но не клавиши. Чтобы Shift+Tab
переключал режим (и не съедал родной цикл permission-режимов — тот переехал
на `meta+m`), добавьте в `~/.claude/keybindings.json` (создайте файл, если нет):

```json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "$docs": "https://code.claude.com/docs/en/keybindings",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "shift+tab": "command:anon",
        "meta+m": "chat:cycleMode"
      }
    }
  ]
}
```

Биндинг действует во всех сессиях, где плагин установлен и включён. Если
отключили плагин — Shift+Tab даст `Unknown command: /anon`: уберите биндинг
или верните `shift+tab` на `chat:cycleMode`. Лаунчер (`anon.ps1`) ставит
такой же биндинг в свой профиль сам.

## Известные ограничения

- Bash-запись (echo \>\>) в память в mid-session-режиме гвардией не закрыта —
  закрывается инструкцией в системном промпте; в launcher-режиме память
  отключена на уровне env.
- Контекст первого хода, собранный до включения, не вырежется — полоса об этом
  честно предупреждает; чистка ограничена побочными файлами сессий
  (`history.jsonl`, `todos/`, `file-history/`) — статистика и логи остаются.
- Заголовок окна, перезаписанный клиентом, мод не переспавнивает по таймеру.
- Windows-first: лаунчер Windows-only, чистка через cmd.exe.

## Статус и лицензия

Экспериментальный личный мод. Лицензия — на усмотрение автора.
