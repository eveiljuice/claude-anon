# claude anon — инкогнито-режим для Claude Code

Режим «как приватное окно браузера»: Claude работает без знания о пользователе,
не оставляет следов на диске и глушит телеметрию, а клиент визуально
перекрашивается в фиолетовый, пока режим активен.

## Что отключено

1. **Чистый контекст** — Claude не видит auto-memory, CLAUDE.md, историю подсказок.
2. **Не сохранять сессию** — транскрипт удаляется при выходе (и при хард-килле —
   дочищивается на следующем старте по манифесту).
3. **Не писать память** — Write/Edit под каталогом сессий движка отказаны.
4. **Без телеметрии** — DISABLE_TELEMETRY, DISABLE_ERROR_REPORTING,
   CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC.

## Два способа включить

- **Полное инкогнито** — запустить `anon.cmd` (или `anon.ps1`): отдельный профиль
  `%USERPROFILE%\.claude-anon`, копия только `.claude.json` и credentials,
  транскрипты отключены на уровне настроек (`cleanupPeriodDays: 0`), память
  отключена env-ами. `/anon off` в этом режиме отказывает — профиль всегда
  анонимен.
- **Внутри обычной сессии** — команда `/anon [on|off]`. Контекст, уже загруженный
  к моменту включения, остаётся (об этом честно говорит полоса). Сессия, где
  `/anon` хоть раз включали, не сохраняется даже после off (sticky).

## Внешне

- фиолетовая полоса над полем ввода с маскотом;
- фиолетовый лейбл `· claude anon` в футере рядом с нативными режимами;
- заголовок окна/вкладки терминала `Claude Code Anon`, пока режим активен.

## Установка мода

`claude plugin install anon-mode@claude-anon` из marketplace (после публикации) —
или через `--plugin-dir <этот репозиторий>\mod\claude-anon` (так делает лаунчер).

## Известные ограничения

- Bash-запись (echo \>\>) в память в mid-session-режиме гвардией не закрыта —
  закрывается инструкцией в системном промпте; в launcher-режиме память
  отключена на уровне env.
- Заголовок окна, перезаписанный клиентом, мод не переспавнивает по таймеру.
- Windows-first: лаунчер Windows-only, чистка через cmd.exe.

## Статус и лицензия

Экспериментальный личный мод. Лицензия — на усмотрение автора.
